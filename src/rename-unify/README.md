# 统一命名工具 (rename-unify) v1.2.0

把音效/影视交付目录里的杂乱文件名，按统一规范批量改名、并按目标归类归位。
规则可随时改，改完存为默认。

> **v1.2.0 的最大变化**：识别模型从「一条规则 → 一个类型串」改成
> **「目标（MIX / BUS / STEM / AIFX）+ 轨道信息（原样保留的自由文本）」**。
> 旧模型认不出 `法老20_DX BUS`、`法老20_Ai FX 1` 这类真实命名 ——
> 实测在 `FinalMix\` 下 **20/28 条识别失败**，其中还包括**你自己已交付的成品**。
> 新模型在同一批 85 个文件上 **0 条失败**（详见文末「回归」）。

## 运行前提

- Windows。双击 `rename-unify.exe` 即可，**无需安装 Python**。
- 首次运行会在 exe 旁生成 `config.json`（记住你的项目信息与目录）。
- 不需要 Pro Tools / 剪映等任何外部程序在线。

## 四个页签

1. **项目信息与模板** —— 填「片名 / 日期 / 版本 / **用户**」四个字段，
   并管理**模板库**（可增删）。页面下方实时显示样例文件名。
2. **目标与归位** —— 目标表：每个目标（MIX / BUS / STEM / AIFX）
   单独指定「归位目录 + 用哪套模板 + 是否启用 + 只作用于哪几集」。
   下方是识别规则表（把历史命名映射到统一格式）。
3. **预览与执行** —— 选目录 →「生成计划」→ 逐行核对 →「执行重命名」。
   **识别失败**的条目可选中后点「手动分类」，当场指定集数 / 目标 / 轨道信息。
4. **回溯与撤销** —— 选 `rename_log_*.csv` →「读取并预览」→「执行撤销」。

## 命名规范

```
{片名} {集数}集 {日期} {版本} {用户}_{轨道信息}.wav
```

| 目标 | 归位 | 文件名 |
|---|---|---|
| MIX（混音成品） | 集根 | `法老 20集 0923 V01 7F_Master.wav` |
| BUS（总线分轨） | `BUS\` | `法老 20集 0923 V01 7F_DX BUS.wav` |
| STEM（分段素材） | `STEM\` | `法老 20集 0923 V01 7F_DX 1.wav` |
| AIFX（AI 音效） | `STEM\` | `法老 20集 0923 V01 7F_Ai FX 1.wav` |

细则：

- 段间用**空格**，轨道信息段用**下划线**与前面隔开。
- 集数自动补零到两位（`9集` → `09集`），保证文件管理器排序正确。
- **轨道信息原样保留**，不补零、不改大小写 —— `DX 1` 不会被改成 `DX 01`
  （否则会把已交付的成品改坏，这是 v1.2.0 明确放弃的「顺手统一」）。
- 扩展名沿用源文件，**模板里不要写 `.wav`**（写了也会被自动剥掉）。

## ⚠️ 「档位」改叫「用户」（v1.2.0）

`7F` 是**你的个人代号**，不是交付档位。字段名统一为 **`{用户}`**。
旧的 `config.json`（`fields.档位`）和旧规则里的 `{档位}` 占位符**会自动迁移**，
不会让谁的配置失效。

## 模板库：每个目标各用一套（v1.2.0）

这是本次的核心诉求 —— Master 要全格式，BUS/STEM 只想保留短名，两条流水线并行：

| 模板名 | 内容 | 典型用法 |
|---|---|---|
| `全格式` | `{片名} {集数}集 {日期} {版本} {用户}_{轨道信息}` | MIX（默认） |
| `短格式` | `{片名} {集数}_{轨道信息}` | BUS / STEM |
| `只改 Master` | MIX 用全格式，**BUS/STEM 填「保持原名」** | 只改成品、素材不动 |
| `保持原名` | 特殊值 —— **只归类不改名** | 只想把文件收进 `BUS\` `STEM\` |

**语义是「分派」不是「复制」**：模板库里可以存很多套，但每个目标只绑一套，
一段音频最后还是**只出 1 个文件**（不会像剪映工具那样按 `模板N/` 各生成一份）。
需要「同一段音频出两份命名」的场景请另说，不塞进目标表以免误勾。

## 手动分类（v1.2.0）

识别不出来的文件**不再静默忽略**：在计划表里选中 →「手动分类」→
填**集数 / 目标 / 轨道信息** → 工具按你填的重新计算落点与文件名。
填完该项立即从「识别失败」变为「待改名」。

判断不了又不想手工填的，就让它保持「识别失败」跳过 —— 工具绝不猜。

## 识别规则

页 2 下半部分是识别规则表，把**历史命名**映射到「目标 + 轨道信息」。
自上而下第一个命中生效。内置规则已覆盖这些真实写法：

| 历史命名 | 目标 | 轨道信息 |
|---|---|---|
| `法老20_Master BUS.wav` | MIX | `Master` |
| `法老20_DX BUS.wav` | BUS | `DX BUS` |
| `法老20_DX 1.wav` | STEM | `DX 1` |
| `法老20_Ai FX 1.wav` | AIFX → STEM | `Ai FX 1` |
| `法老 17集 0922 V01 7F_MX Verb ST.wav` | STEM | `MX Verb ST` |
| `法老13_FX 2.dup1.wav` | STEM | `FX 2.dup1`（**标记为疑似衍生文件**，请确认是否交付） |

规则里可用的占位符：

| 占位符 | 含义 |
|---|---|
| `{片名}` | 剧名/项目名 |
| `{集数}` | 数字 + 「集」字 |
| `{裸集数}` | 纯数字（用于 `法老20_DX` 这类无「集」字的旧命名） |
| `{日期}` | 4–8 位数字 |
| `{版本}` | `V` + 数字 |
| `{用户}` | 1–8 位字母数字（v1.1.0 里叫 `{档位}`） |

改错了点「恢复内置规则」即可回到出厂状态。

## 安全设计

- **先计划后执行**：所有改动先在计划表里列出并逐行标注状态
  （待改名 / 已是目标名 / 识别失败 / 命名冲突 / 按清单排除），只有「待改名」的才会动。
- **已合规绝不动**：已经符合目标命名的文件判「已是目标名」跳过 ——
  这是不能让步的承诺（v1.2.0 回归里，你自己交付的 17 集 14 个文件**一个都没被碰**）。
- **冲突即拦截**：目标名在本批内重复、或已被别的现存文件占用 → 标「命名冲突」跳过，**绝不覆盖**。
- **可撤销**：每次执行写一份 `rename_log_*.csv`，页 4 一键改回。
- **按钮门控**：没有「待改名」项时，「执行重命名」是灰的，点不动。

## 回归（v1.2.0 实测）

在 `D:\DAW-Project\13-法老D_20260922_7F\FinalMix\`（85 个 wav）上：

| 指标 | v1.1.0 | v1.2.0 |
|---|---|---|
| 识别失败 | 20 / 28 样例（含已交付成品） | **0 / 85** |
| 命名冲突 | — | 0 |
| 已合规、不动 | — | 15 |
| 待改名 / 需移动 | — | 70 / 53 |

关键验证点（全部通过）：

- 17 集 14 个文件**全部判「已合规」**，一个都不动
- 12 集 Master 保留 `0922`，同集其它文件**继承本集的 0922**（不出现 0922/0923 并存）
- `法老20_Master BUS` → 集根 `法老 20集 0923 V01 7F_Master.wav`
- `法老20_DX BUS` → `20\BUS\…_DX BUS.wav`
- `法老20_Ai FX 1` → `20\STEM\…_Ai FX 1.wav`

## 已知边界

- 只改文件名、只移动文件，**不改目录名、不动文件内容**。
- 撤销依赖日志文件；日志被删就没法自动撤销（可手工改回）。
- 识别失败的文件会列出来并跳过，**不静默忽略** —— 可加规则，或用「手动分类」当场指定。
- `FX 1 MON`、`FX 2.dup1` 这类衍生文件会自动归 STEM，但**只提示不处置**：
  要不要一并交付由你决定。
