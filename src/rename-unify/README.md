# 统一命名工具 (rename-unify) v1.1.0

把音效/影视交付目录里的杂乱文件名，按统一规范批量改名；并可顺手把平铺的
交付目录「按集归位」。规则可随时改，改完存为默认。

## 运行前提

- Windows。双击 `rename-unify.exe` 即可，**无需安装 Python**。
- 首次运行会在 exe 旁生成 `config.json`（记住你的项目信息与目录）。
- 不需要 Pro Tools / 剪映等任何外部程序在线。

## 四步用法

1. **项目信息与模板**：填「片名 / 日期 / 版本 / 档位」四个字段，模板里用占位符引用。
   页面下方实时显示样例文件名，改一个字符就能看到效果。
2. **命名清单（勾选）**：勾选本次要产出的交付类型，可限定只对某几集生效。
   例：第 1 集只需交 BUS → 只勾 BUS-*，其余取消勾选。
3. **预览与执行**：选目标目录 → 点「生成计划」→ 逐行核对变更计划 → 点「执行重命名」。
   需要的话勾上「按集归位」，改名完自动把文件收进「每集一个文件夹」。
4. **回溯与撤销**：每次执行都生成 `rename_log_*.csv`。选日志 →「读取并预览」→
   需要时「执行撤销」把名字（和归位移动）一并改回去。

## 命名规范

```
{片名} {集数}集 {日期} {版本} {档位}_{类型}.wav
```

段间用**空格**，类型段内用**下划线 + 连字符**。示例：

| 类型 | 文件名 |
|---|---|
| 总线分轨 | `前夫 01集 0920 V01 7F_BUS-DX.wav` |
| 混音成品 | `前夫 08集 0920 V01 7F_MIX.wav` |
| 混音终稿 | `前夫 09集 0920 V01 7F_MIX-MASTER.wav` |
| 分段素材 | `前夫 10集 0920 V01 7F_STEM-MX-02.wav` |

细则：

- 集数自动补零到两位（`9集` → `09集`），保证文件管理器里排序正确。
- 扩展名一律沿用源文件，**模板里不要写 `.wav`**（写了也会被自动剥掉）。
- 类型段尾部的数字自动补零（`-2` → `-02`）。

## 命名清单（v1.1.0 新增）

交付类型并非每集都一样 —— 第 1 集可能只交 BUS，第 4 集才补 STEM。
用「勾选 + 集数限定」表达这种差异，比改模板或事后挪文件都安全。

- **启用列**：双击切换 `[√] 启用` / `[ ] 停用`。
- **生效集数列**：双击输入。留空 = 全部集；填 `1` 或 `1,3-5` 可只对指定集生效。
- 表内颜色：绿色=启用全部集，橙色=启用了但有集数限定，灰色=已停用。
- 未勾选（或集数不匹配）的文件在「生成计划」时标为 **`按清单排除`** 并跳过，
  **不改名、不移动**。
- 类型支持通配：`STEM-DX-*` 表示「STEM-DX 开头的任意序号」。
  ⚠️ STEM 类型自带序号（`STEM-DX-01`、`STEM-MX-02`），所以默认项带尾随 `*`；
  若手工改成 `STEM-DX`，会一条都匹配不上。
- 清单留空 = 不启用过滤（等同于旧版本行为）。

## 按集归位（v1.1.0 新增，原 `FinalMix按集归位.ps1` 已并入）

勾选「3 · 预览与执行」页的 **「重命名完成后，自动按集归位」**，改名完自动重组结构：

```
FinalMix/
├── 前夫 01集 0920 V01/              ← MIX / MIX-MASTER 放集根目录
│   ├── 前夫 01集 0920 V01 7F_MIX.wav
│   └── BUS/
│       └── 前夫 01集 0920 V01 7F_BUS-DX.wav
└── 前夫 09集 0920 V01/
    ├── 前夫 09集 0920 V01 7F_MIX-MASTER.wav
    └── STEM/
        └── 前夫 09集 0920 V01 7F_STEM-MX-02.wav
```

- 归类规则：`MIX`/`MIX-MASTER` → 集根目录；`BUS-*` → `集目录\BUS`；`STEM-*` → `集目录\STEM`。
- 归位目标留空 = 直接用「目标目录」。
- 安全语义：**只移动、绝不覆盖**；解析不了集前缀的跳过并报告；
  可选「归位后清理搬空的类别文件夹」。
- 撤销：改名与归位写入**同一份日志**，撤销时按倒序先反归位、再反改名。

## 换项目怎么办

改页1 的四个字段值，模板不动；按需在页2 调整清单勾选。例如换成「誓言」第 5 集、日期 0925：

| 字段 | 值 |
|---|---|
| 片名 | 誓言 |
| 日期 | 0925 |
| 版本 | V01 |
| 档位 | 5F |

改完点「保存为默认」，下次打开就是这套。

## 识别规则

页1 下半部分是识别规则表，把**历史命名**映射到统一格式。自上而下第一个命中生效。
内置规则已覆盖这些历史写法：

| 历史命名 | 统一为 |
|---|---|
| `前夫 10集 0920 V01 7F_DX BUS.wav` | `前夫 10集 0920 V01 7F_BUS-DX.wav` |
| `前夫1_DX Folder.wav` | `前夫 01集 0920 V01 7F_BUS-DX.wav` |
| `前夫2_BUS DX Folder.wav` | `前夫 02集 0920 V01 7F_BUS-DX.wav` |
| `前夫 1集 0920 V01 7F.wav` | `前夫 01集 0920 V01 7F_MIX.wav` |
| `前夫 10集 0920 V01 7F_Master.wav` | `前夫 10集 0920 V01 7F_MIX-MASTER.wav` |
| `前夫 10集 0920 V01 7F_MX 2.wav` | `前夫 10集 0920 V01 7F_STEM-MX-02.wav` |

规则里可用的占位符：

| 占位符 | 含义 |
|---|---|
| `{片名}` | 剧名/项目名 |
| `{集数}` | 数字 + 「集」字 |
| `{裸集数}` | 纯数字（用于 `前夫1_DX` 这类无「集」字的旧命名） |
| `{日期}` | 4–8 位数字 |
| `{版本}` | `V` + 数字 |
| `{档位}` | 1–8 位字母数字 |

「输出类型」列用 `\g<lane>` 引用匹配到的轨道组（如 `DX`/`FX`/`MX`）。
改错了点「恢复内置规则」即可回到出厂状态。

## 安全设计

- **先计划后执行**：所有改动都先在「变更计划」表里列出来，逐行标注状态
  （待改名 / 已是目标名 / 识别失败 / 命名冲突 / 按清单排除），只有「待改名」的才会动。
- **冲突即拦截**：目标名在本批内重复、或已被别的现存文件占用，该条自动标为「命名冲突」
  并跳过，**绝不覆盖**。（归位同理：目标已存在则跳过。）
- **幂等**：已经符合规范的文件显示「已是目标名」并跳过，重复执行不会叠加后缀。
- **可撤销**：每次执行写一份 `rename_log_*.csv`，页4 可一键改回原文件名与位置。
- **执行前提条件门控**：没有「待改名」项时，「执行重命名」按钮是灰的，点不动。

## 已知边界

- 只改文件名、只移动文件，**不改目录名、不动文件内容**。
- 撤销依赖日志文件。日志被删掉就没法自动撤销（但可以手工改回）。
- 识别失败的文件会列出来并跳过，不会静默忽略 —— 说明该命名不在规则覆盖范围内，
  可在页1 加一条规则。
- 归位功能的「集前缀」优先用识别引擎推导；识别不出时回退按分隔标记（默认 ` 7F_`）字面切分。
  新项目档位不同（如 `5F`）而文件名尚未统一时，先跑一遍改名再归位。

```
  code\

```
