# pt-project-folder-builder

**PT 工程文件夹生成器** —— 按视频文件或集数列表，批量建立 Pro Tools 工程文件夹，
并从模板复制 `.ptx`。已存在的自动跳过。

零第三方依赖（仅标准库 + tkinter）。

## 入口

```bash
python folder_builder_gui.py
```

打包：仓库根执行 `python tools/build.py pt-project-folder-builder`（或本目录 `.\build.ps1`）。

## 输入

| 项 | 说明 |
|---|---|
| 集数 | 如 `1-10, 23, 38, 46-49`（逗号分隔 + 连字符区间，自动去重排序） |
| 项目名称 | 如 `誓言`（对应命名里的「项目名」） |
| 输出路径 | 新项目根建在此路径下，默认 `D:\DAW-Project` |
| 模板路径 | 含 `.ptx` 的模板目录，默认 `D:\DAW-Project\00文件夹模板` |

## 命名规则

```
{序号}-{项目名}{等级}_{日期}_{用户名}
例：10-誓言D_20260920_7F
```

- 「规则」（结构，固定）与「信息」（序号 / 项目名 / 等级 ABCD / 日期 / 用户名，均可改）拆开
- 集数文件夹默认「项目名 + 数字」（如 `睡父亲1`），可切换为「纯数字」或「项目名 + 等级 + 数字」

## 行为与安全约定

- 重复运行**只补缺的**：已存在项按勾选「跳过」或「覆盖」
- 复制 `.ptx` 时**先确认模板可复制，再动目标文件** ——
  若模板 `.ptx` 在规划后被移走/改名，会报告跳过而**不会**「删掉旧文件却没补上新的」
- 生成前有预览（项目根 / 分类目录 / 步骤列表）可核对

## 配置

GUI 内即时可调，无独立配置文件（路径与命名信息每次运行可改）。
